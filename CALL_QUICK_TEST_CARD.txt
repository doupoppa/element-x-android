质量指标：       语音: 16kHz 单声道，视频: H.264/VP8

🔧 测试环境准备
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ 预授权（可选，UI 会请求）
   adb shell pm grant io.element.android.x android.permission.RECORD_AUDIO
   adb shell pm grant io.element.android.x android.permission.CAMERA

2️⃣ 验证设备
   adb shell getprop ro.product.model           # 设备型号
   adb shell getprop ro.build.version.release   # Android 版本
   adb shell dumpsys package com.android.webview | grep version

3️⃣ 启动应用
   adb shell am start -n io.element.android.x/.MainActivity

4️⃣ 实时监控日志
   adb logcat | grep -E "ElementCall|WebView|MediaCodec"

【语音通话 - E2.1】P0 必测

步骤1: 打开群聊或私聊
  □ 应用正常运行
  □ 聊天列表可见

步骤2: 点击通话按钮
  □ 菜单中出现"语音通话"选项
  □ 点击后 WebView 加载中...（< 3 秒）

步骤3: 权限请求
  □ 弹出"允许 GTalk 使用麦克风？"
  □ 点击"允许"

步骤4: 通话建立
  ✓ 关键指标
    □ Element Call 界面加载
    □ 显示"呼出中..." 或对端信息
    □ < 5 秒建立连接（红色 → 绿色）
    □ 显示对端头像和昵称

步骤5: 音频验证
  ✓ 音质评分
    □ 对端能清楚听到你说话
    □ 你能清楚听到对端回复
    □ 无明显杂音/echo/延迟
    □ 延迟感受 < 500ms

  ✓ 操作
    □ 点击麦克风图标 → 通话静音 → 对端听不到
    □ 再点击 → 通话恢复 → 对端重新听到
    □ 点击喇叭图标 → 扬声器/听筒切换

步骤6: 通话中的应用交互
  □ 横屏 → 竖屏旋转无中断
  □ 打开后台应用无崩溃
  □ 返回通话界面通话继续

步骤7: 挂断
  □ 点击红色"挂断"按钮
  □ 返回聊天界面
  □ 无崩溃或卡顿

【视频通话 - E2.2】P0 必测

步骤1-3: 同语音通话（1-3）

步骤4: 权限请求 (视频增加)
  □ "允许 GTalk 使用相机和麦克风？"
  □ 同时请求两个权限

步骤5: 视频建立
  ✓ 关键指标
    □ 本地相机预览出现（左下或右下小窗）
    □ 预览帧率稳定 (30fps)
    □ 对端视频显示（主屏幕或大窗口）
    □ < 5 秒完全建立

步骤6: 视频质量
  ✓ 本地预览
    □ 清晰度OK（480p 或更高）
    □ 亮度自动调节
    □ 前置摄像头可用

  ✓ 对端视频
    □ 对端画面清晰可见
    □ 无明显卡顿或冻屏
    □ 分辨率自适应（宽带 > 狭带）

步骤7: 摄像头切换
  □ 点击摄像头切换按钮
  □ 从前置 → 后置（或反之）
  □ 画面无黑屏，平滑切换

步骤8: 视频静音
  □ 点击相机图标 → 本地视频停止
  □ 对端显示静止画面或黑屏
  □ 音频继续

步骤9: 旋转&多任务
  □ 横屏旋转无卡顿
  □ 打开其他应用返回视频继续

步骤10: 长通话
  □ 通话 5 分钟以上
  □ 无明显发热
  □ 性能稳定

⚠️ 常见问题排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【问题】WebView 加载很慢 (> 5 秒) / 空白
  【原因】
    1. 网络延迟 (> 1s RTT)
    2. Element Call 服务不可达
    3. WebView 版本过旧 (< 90)

  【诊断】
    adb logcat | grep "ElementCall\|WebView"
    adb shell getprop com.android.webview.vmsize

  【解决】
    • 检查网络连接
    • 确认 https://call.element.io 可访问
    • 升级系统 WebView

---

【问题】权限请求后应用卡住/崩溃
  【原因】
    1. 权限处理异常
    2. WebRTC 初始化失败

  【诊断】
    adb logcat | grep "AndroidRuntime\|FATAL"

  【解决】
    • 清除应用数据：adb shell pm clear io.element.android.x
    • 重新启动应用

---

【问题】相机预览黑屏 (视频通话时)
  【原因】
    1. CAMERA 权限未授予
    2. 相机被其他应用占用
    3. 相机驱动异常

  【诊断】
    adb shell dumpsys package io.element.android.x | grep CAMERA
    adb shell "dumpsys media.camera" | grep -E "open|InUse"

  【解决】
    • 预授权：adb shell pm grant io.element.android.x android.permission.CAMERA
    • 关闭其他相机应用（如 QQ、WeChat）
    • 重启手机

---

【问题】声音单向 (自己能听到对端，对端听不到自己)
  【原因】
    1. RECORD_AUDIO 权限缺失
    2. 麦克风被占用或故障
    3. 音频路由错误

  【诊断】
    adb shell dumpsys package io.element.android.x | grep RECORD_AUDIO
    adb shell dumpsys audio | grep -i "mic\|microphone"

  【解决】
    • 预授权麦克风
    • 检查麦克风是否工作：adb shell record test.wav (Ctrl-C 停止)
    • 检查手机设置中的麦克风权限

---

【问题】高延迟 (> 1 秒)
  【原因】
    1. 网络质量差 (丢包 > 5%, 抖动 > 200ms)
    2. SFU 距离远 (地理位置)
    3. 编码器性能不足

  【诊断】
    # 测试网络延迟
    ping call.element.io

    # 监控性能
    adb shell dumpsys meminfo io.element.android.x | grep "TOTAL:"

  【解决】
    • 切换到更好的网络 (5G / 家里 WiFi)
    • 降低视频分辨率 (自动)
    • 关闭其他网络消耗应用

---

【问题】通话频繁掉线
  【原因】
    1. WebSocket 连接不稳定
    2. 网络切换 (WiFi ↔ 4G)
    3. 防火墙/代理阻止

  【诊断】
    adb logcat | grep "WebSocket\|CLOSE"

  【解决】
    • 连接稳定的 WiFi
    • 确保防火墙未阻止 call.element.io:443
    • 避免网络切换期间进行通话

---

【问题】应用 OOM / 内存泄漏 (30分钟后崩溃)
  【原因】
    1. WebRTC 视频缓冲未正确释放
    2. 媒体编码器资源泄漏

  【诊断】
    # 监控内存
    adb shell "while true; do dumpsys meminfo io.element.android.x | grep TOTAL; sleep 2; done"

  【解决】
    • 降低视频分辨率
    • 避免长时间连续视频通话 (> 60 分钟)
    • 定期重启应用

📊 性能基准数据
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

建立时间：
  语音通话：< 5 秒
  视频通话：< 8 秒

内存占用：
  待机：    ~150 MB
  语音：    ~180 MB
  视频：    ~280 MB (720p)
  极限：    < 400 MB (避免 OOM)

网络带宽（推荐）：
  语音：    128 kbps (最低 64 kbps)
  视频 480p：1.5 Mbps
  视频 720p：3.0 Mbps
  视频 1080p：6.0 Mbps

延迟目标：
  端到端延迟 (RTT)：< 300 ms
  可接受：         < 500 ms
  用户能察觉：     > 1000 ms
